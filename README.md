## 选机场的三条纪律

1. **先买月付，跑满一个完整周期再谈续费。** 晚高峰掉不掉线、你要用的服务能不能开，一个月足够暴露。
2. **别看节点数量。** 一个机场写 300 个节点不等于 300 条线路，很多是同一台机器换不同名字。
3. **跑路看行为不看承诺。** 官网还在卖年付、客服已经三天不回、节点全红，这三件同时出现基本就是跑了。
